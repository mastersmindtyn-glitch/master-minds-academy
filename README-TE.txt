MASTER MINDS ACADEMY – ONLINE ANDROID APP

ఈ ప్రాజెక్ట్ Android WebView యాప్. ఇది మీ GitHub Pages వెబ్‌సైట్‌ను ఇంటర్నెట్ ద్వారా తెరుస్తుంది.
Website URL:
https://mastersmindtyn-glitch.github.io/master-minds-academy/

APK build చేయడానికి:
1. ఈ ZIP ను GitHub లో కొత్త repository (ఉదా: master-minds-android) లో upload చేయండి.
2. అన్ని folders సహా project files upload చేయాలి.
3. GitHub repository లో Actions tab తెరవండి.
4. Build Android APK workflow ఎంచుకుని Run workflow నొక్కండి.
5. Build పూర్తయిన తర్వాత workflow run లో Artifacts దగ్గర master-minds-academy-apk.zip డౌన్‌లోడ్ చేయండి.
6. ZIP extract చేసి app-debug.apk ను Android ఫోన్‌లో install చేయండి.

గమనిక: APK తయారీకి ముందు GitHub Pages website URL live గా పనిచేస్తోందని నిర్ధారించండి. ఈ app కు internet అవసరం. Student Login ప్రస్తుతం website లో ఉన్న demo login మాత్రమే; secure user accounts కావాలంటే backend అవసరం.
